# Modern Dark RPL Portfolio - Digital CV

Proyek portofolio dan digital CV modern dengan tema dark mode untuk siswa SMK jurusan Rekayasa Perangkat Lunak (RPL). Desain di-generate dan diekspor menggunakan Google Stitch.

## 🚀 Fitur Utama
- **Modern Dark Aesthetic**: Menggunakan palet warna neon ambient, glassmorphism, dan tipografi modern (JetBrains Mono & Plus Jakarta Sans).
- **Profil & Identitas Digital**: Kartu identitas, avatar status, dan bio keahlian.
- **Skills Matrix**: Indikator persentase keahlian teknologi (HTML/Tailwind, PHP/Laravel, JavaScript/React, MySQL, Git/GitHub).
- **Portfolio Showcase**: Galeri proyek unggulan lengkap dengan tech stack badge.
- **Riwayat Pengalaman & Pendidikan**: Timeline pengalaman magang/proyek dan riwayat SMK.
- **Form Kontak & CTA**: Tombol unduh CV dan kontak interaktif.

## 📁 Struktur File
- `index.html`: File halaman web utama portofolio.
- `screen_1_avatar.png`: Avatar profil siswa RPL.
- `screen_2_cv_screenshot.png`: Cuplikan tampilan lengkap desain.

## 🛠️ Menjalankan Proyek
Cukup buka file `index.html` di browser Anda (Google Chrome, Edge, Firefox, dll).
